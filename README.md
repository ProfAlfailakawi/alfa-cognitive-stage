# ALFA Cognitive Stage — الاستوديو المعرفي للمحاضرات

استوديو تعليمي تفاعلي مستقل، يعمل أساساً في المتصفح، يدعم ملفات PowerPoint وعرض المحاضر/الطلبة، والتصويت، ومخرجاً صوتياً تجريبياً، ورسومات SVG خفيفة، وذاكرة محلية للمشاهد المعتمدة.

## البدء على macOS

**للاستخدام اليومي:** افتح `Start ALFA.command` بالنقر المزدوج، ثم افتح صفحة المحاضر على `http://localhost:4173/#presenter`. يجهز التشغيل مكتبات Python المطلوبة تلقائياً أول مرة ويصلحها عند الحاجة؛ لا تثبّتها يدوياً. اترك نافذة Terminal مفتوحة.

للتجهيز الأول وتفاصيل التثبيت راجع [دليل Mac العربي](docs/MAC_SETUP_AR.md). المتطلبات: Node.js 22، Python 3، LibreOffice، Poppler، FFmpeg، python-pptx، lxml، Pillow.

الطريقة اليدوية إن احتجتها:

```bash
npm start
```

سيطبع Terminal **رمز المحاضر**. لا تشاركه مع الطلبة. إذا لم توجد حزمة، سترى شاشة رفع PPTX مباشرة.

## أين تظهر المزايا؟

- **استيراد PPTX وPDF (وKeynote بأفضل جهد):** [التفاصيل](docs/IMPORT_FORMATS_AR.md). من لوحة المحاضر مباشرة مع رمز الإدارة؛ يُستعمل المحتوى نفسه عند المحاضرات التالية. تُحمّل صور الشرائح المجاورة مسبقاً وتُخزن مؤقتاً لتسريع التنقل.
- **الواجهة الموحدة:** الشريحة والتحكم والملاحظات والمايك والإنفوجرافيك والتصويت في مكان واحد.
- **الحركات:** نقرات PowerPoint (ظهور العناصر والفقرات وبناء المخططات) تُعرض خطوة بخطوة بترتيبها وحالتها؛ شكل الحركة تلاشٍ هادئ، وما لا يُدعم يُعلن في لوحة الجاهزية — [التفاصيل](docs/PPTX_BUILD_STEPS_AR.md). الفيديوهات وسائط مستقلة.
- **العودة بعد الاستطراد:** `E` تعيد الشريحة ونقرة الحركة والفيديو كما كانت.
- **المخرج الخفي:** استماع اختياري من Chrome، مع إحصائية/قصة/مقارنة/سؤال، كله محلي وبلا أي API أو تكلفة. هذا ليس بعدُ ذكاءً دلالياً مستمراً لكل المحاضرات.
- **الرسومات:** 10 أنواع SVG بسيطة دون توليد صور: stat، compare، steps، concept، flow، timeline، story، bars، cycle، activity ([التفاصيل](docs/SCENES_AR.md)).
- **التصويت:** لوحة داخل الاستوديو، QR للطلبة عبر LAN، نتائج مباشرة وإعادة جولات، ومقارنة نسب جولات السؤال وتصدير CSV مجمّع؛ يحتاج الشبكة نفسها أو استضافة خاصة.
- **الذاكرة:** حفظ المشاهد في المتصفح وعلى الخادم بعد إدخال رمز الإدارة؛ الإعادة بلا طلبات OpenAI جديدة عند مطابقة محفوظة.
- **نبض الفهم والمراجعة والبروفة:** زرّا «فاهم/ضايع» المجهولان، وتنبيه خاص عند مخالفة رقم تنطقه لما في الشريحة، ومقترح واحد قبل المحاضرة القادمة، ومراجعة تنشرها للطلاب من مشاهد محاضرتك فقط، وأسئلة سابقة حقيقية للتدرّب — [التفاصيل](docs/INSIGHT_AR.md).
- **للتجربة الميدانية:** محاضرة تجريبية مسجّلة بموافقتك وتقرير تصنّف قراراته بنفسك، واستئناف الموضع بعد انقطاع، وخريطة مقرر، وبروفة جمهور موقّتة، ووضع ضيف (`npm run start:guest` مع `?guest=1`) — [التفاصيل](docs/FIELD_TRIAL_AR.md).
- **التنقل بالصوت:** «الشريحة التالية»، «السابقة»، «روح للشريحة خمسة»؛ بأوامر كاملة فقط، ويتوقف أثناء الفيديو، وفيه تراجع — [التفاصيل](docs/VOICE_PATH_AR.md).
- **الخصوصية:** لا يُرسل مفتاح OpenAI إلى المتصفح، وملفات الشرائح والملاحظات لا تُشارك؛ أي طلب بعيد (هاتف/نفق) يرى صفحة التصويت فقط — [المشاركة الآمنة](docs/SECURE_SHARING_AR.md).

## حدود التجربة الحالية

حركات التأكيد والمسارات وSmartArt غير مدعومة، وفهم الذكاء الاصطناعي ليس بثاً صوتياً كاملاً، والتعرف الصوتي قد يستعين بخدمة Chrome الخارجية. لم نختبر هذه النسخة بعد على Mac الحقيقي أو 5 هواتف فعلية أو شبكة الجامعة.

لمعرفة حالة كل متطلب بالتفصيل، اقرأ **[مصفوفة القبول](docs/ACCEPTANCE_MATRIX_AR.md)** و**[التدقيق الشامل](docs/SPEC_STATUS_AR.md)**؛ ومن الوثائق: [المشاهد](docs/SCENES_AR.md)، [التحصين](docs/HARDENING_AR.md)، [الصوت](docs/VOICE_PATH_AR.md)، [التفاعل](docs/ENGAGEMENT_AR.md)، [نبض الفهم والمراجعة](docs/INSIGHT_AR.md)، [الذاكرة](docs/SEMANTIC_MEMORY_AR.md)، [المكتبة والبروفة](docs/LIBRARY_REHEARSAL_REPORTS_AR.md)، [الاستيراد](docs/IMPORT_FORMATS_AR.md)، [المشاركة الآمنة](docs/SECURE_SHARING_AR.md).

## الاختبارات

```bash
npm run test:director
npm run test:vote
npm run test:e2e
npm run test:build
```

اختبارات المتصفح تحتاج Playwright؛ اختبارات GitHub Actions تثبّت التبعيات وتنشئ محاضرة اختبار تلقائياً.

## اختصارات العرض

| الاختصار | الوظيفة |
|---|---|
| → / PageDown / مسافة | الشريحة التالية |
| ← / PageUp | الشريحة السابقة |
| Home | أول شريحة |
| E / Esc | إلغاء الاستطراد وإخفاء المشاهد والعودة إلى الشريحة الحالية |
| V | تشغيل/إيقاف الفيديو |

## لا تكلفة

لا يستدعي المشروع أي خدمة مدفوعة: لا مفتاح API ولا نموذج سحابي (حُذف التحليل السحابي بالكامل). التعرف على الصوت يتم في المتصفح (Chrome أو Safari). إن أردت رابطاً عاماً لهواتف الطلبة ضع في `.env`: `PUBLIC_URL=http://192.168.1.10:4173`.

**مهم:** استخدام المشروع في قاعة فعلية يتطلب بروفة على جهاز Mac بنفسه، خصوصاً الحركات، الفيديو والصوت والتصويت على هواتف الطلبة.
