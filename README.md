# ALFA Cognitive Stage

منصة عرض للمحاضرات بوضعين: **نافذة المحاضر** (ملاحظات وتحكم) و**نافذة الطلبة** (الشريحة فقط بلا أدوات).

## ما يعمل الآن (مُختبَر)

- **تحويل ملف PowerPoint إلى حزمة محاضرة** (`tools/build_bundle.py`):
  - يعرض الشرائح كما هي بمحرك LibreOffice، فيحافظ على التصميم والخطوط.
  - يستخرج الفيديوهات المضمّنة ويحفظ موضعها ومقاسها من الشريحة.
  - يحوّل الفيديو إلى MP4 (H.264) ونسخة WebM احتياطية، ويحفظ ملاحظات المحاضر.
  - لا يعدّل ملف PowerPoint الأصلي، ولا يُرفع إلى Git.
  - يسجّل الروابط الخارجية المكسورة في `problems` داخل الـmanifest.
- **العرض في المتصفح** (`web/`): تنقّل بالأسهم والمسافة، ونافذة ثانية للطلبة تتزامن معها عبر `BroadcastChannel`.
- **الفيديو**: تشغيل وإيقاف ومزامنة مع نافذة الطلبة، وتحديد موضعه وفق الشريحة.
- **العودة الفورية**: زر أو مفتاح `E` يوقف الفيديو ويعيد الشريحة الأساسية.
- **التصويت الطلابي** (`server/votes.mjs`، `web/vote.html`، `web/vote-admin.html`):
  - المحاضر يفتح «التصويت» من شاشته، ينشئ جلسة برمز QR، ويضيف أسئلة من 2 إلى 6 خيارات.
  - الطالب يمسح QR ويجيب دون حساب. كل جهاز يحصل على رمز عشوائي محلي، ويُمنع التصويت المكرر إلا إن سُمح بالتغيير.
  - سؤال واحد مفتوح في كل مرة. الطالب الذي ينتظر يرى السؤال التالي تلقائياً دون إعادة فتح الرابط.
  - النتائج تُحفظ في `data/votes.json` وتبقى بعد إعادة تشغيل الخادم.
  - الحد: صوت واحد لكل جهاز كل 500 ms، و1000 مشارك كحد أقصى لكل سؤال، وطلب بحجم 4 KB كحد أقصى.
- **اختبارات**:
  - `npm run test:build`: اختبارات بناء الحزمة (بدون محرك العرض).
  - `npm run test:e2e`: فحوص المتصفح للعرض (التنقّل والتزامن والفيديو والعودة).
  - `npm run test:vote`: فحوص التصويت بخمسة أجهزة متصفح منفصلة، والتكرار، والتغيير، والنتائج بعد إعادة التشغيل.

- **الإنفوجرافيك المباشر** (`web/infographic.js`): من لوحة المحاضر، زر «إنفوجرافيك»، تختار نوع البطاقة وتكتب النص. ثلاثة أنواع: بطاقة إحصائية، ومقارنة، وخطوات. كل الأرقام والكلمات من إدخال المحاضر، ولا يضيف الكود أي معلومة. يُخفى تلقائياً عند تغيير الشريحة، ويُخفى مع زر العودة.
- **المحاضرتان**: الملف الأصلي مقسوم إلى محاضرتين، الأولى (21 شريحة) والثانية (32 شريحة)، وكل واحدة لها حزمتها. قائمة الاختيار في شاشة المحاضر.

## تحديث المخرج الخفي والتصويت — 17 أكتوبر 2026

- تم إصلاح العودة إلى **الشريحة الحالية**، بدلاً من الرجوع إلى أول العرض، وعدم مقاطعة حقول الإدخال باختصارات الشرائح.
- تم إضافة نصوص الشرائح إلى حزمة المحاضرة لربط الفهم بسياقها؛ يُجدد نص الحزم القديمة عند إعادة تشغيل أداة البناء.
- تم إضافة تعرف صوتي تجريبي في نافذة المحاضر عبر Web Speech API: اضغط **بدء الاستماع** في Chrome.
- في الوضع المتوازن قد تظهر بطاقة **إحصائية واضحة منطوقة** تلقائياً. يتعرف النظام مبدئياً على بداية القصة والمقارنة والسؤال، لكن لا يحوّلها بعد إلى مشاهد روائية كاملة. يوجد وضع ظل ومحافظ.
- يمكن تجربة الجمل في حقل **اختبار نصي دون المايك**. هذا للاختبار وليس برومبتاً مطلوباً في المحاضرة.
- يمكن تفعيل فهم اختياري باستخدام OpenAI عبر API محمي برمز المحاضر؛ النتائج لا تظهر دون موافقة.
- التصويت الآن يولّد QR بعنوان شبكة Mac عندما يتوفر، ويتيح **جولة جديدة** للسؤال نفسه مع نتائج مستقلة وتحديث نتائج الهواتف.
- يتم التعامل مع أكثر من فيديو مضمن على الشريحة برمجياً، لكن تشغيل الصوت ومزامنة المتصفح مع العرض الخارجي يحتاجان اختبار Mac.

### إعداد API الاختياري

يقرأ الخادم ملف `.env` المحلي باستخدام Node.js 22. مثال (احتفظ بالمفتاح سرياً):

    OPENAI_API_KEY=YOUR_PRIVATE_KEY
    OPENAI_MODEL=gpt-4.1-mini
    DIRECTOR_MAX_CALLS=24
    # PUBLIC_URL=http://192.168.1.10:4173

إذا لم يوجد مفتاح فبإمكانك الاستمرار في عرض المحاضرة والتصويت المحلي دون استدعاء OpenAI. إن أردت تشغيل المخرج السحابي، أدخل **رمز المحاضر** الظاهر في Terminal في واجهة المخرج ثم فعّل المربع المخصص. تظل مشاهد AI اقتراحات للمراجعة.

**تحذير خصوصية:** تعرف الكلام في Chrome قد يستعين بخدمات المتصفح الخارجية، حتى عندما لا تستخدم OpenAI؛ لذلك **لا تعتبره محرك صوت محلياً أوفلاين**. وضع صفر API يعني عدم إرسال طلبات OpenAI من تطبيقنا؛ الصوت المحلي الحقيقي ما زال في خطة التطوير.

تفاصيل ما هو منفذ وما هو ناقص: [تدقيق المواصفات](docs/SPEC_STATUS_AR.md).

## ما لم يُنفَّذ بعد

- **الحركات (Animations) داخل الشرائح**: لا تُنقل حتى الآن. الشرائح صور ثابتة، ولا نضمن المحافظة على حركات الإحصائيات.
- **المخطط البياني الأصلي**: الإحصائيات في المحاضرة صور، لذلك لا توجد حركات مخططات تُنقل.
- **المخرج الذكي الخفي الكامل**: تم ربط مايك تجريبي وقواعد محلية واتصال AI اختياري، لكن فهم القصة وتطويرها بصرياً وذاكرة السياق الشاملة **غير مكتملين**.
- **مفتاح API**: يُقرأ من `.env` على الخادم دون عرضه للمتصفح. الاتصال لم يُختبر بمفتاح فعلي.
- **استضافة التصويت على الإنترنت**: التصويت يعمل حالياً على الخادم المحلي فقط. الطلبة يحتاجون الوصول إلى الخادم عبر الشبكة، وهذا يتطلب استضافة خارجية لم تُختر بعد، وسأبحث عن خدمة مجانية وأختبرها قبل اعتمادها.
- **التصويت على الهواتف الحقيقية**: رغم إصلاح رابط الشبكة والجولات، الاختبارات السابقة افتراضية؛ يلزم اختبار أجهزة حقيقية.
- **المشاهد البصرية الدلالية المتقدمة**: AI يولد اقتراحات من ثلاثة أنواع عند تفعيله، لكن المسرح القصصي وخرائط المفاهيم والمحاكاة **غير منفذة**.
- **اختبار على Mac وPowerPoint**: لم يُجرَ. الاختبارات هنا على Chromium وLibreOffice فقط.

## التشغيل

المتطلبات: Node.js 22، Python 3 مع `python-pptx` و`lxml` و`Pillow`، وLibreOffice وpoppler (`pdftoppm`) وffmpeg.

```bash
python3 tools/build_bundle.py /path/to/lecture.pptx   # يكتب bundles/<id>/ ويحدّث current.json
npm start                                             # ثم افتح http://localhost:4173
```

- المحاضر: `http://localhost:4173/#presenter`
- الطلبة: يُفتح من زر «فتح نافذة الطلبة» أو `http://localhost:4173/#audience`

اختبارات المتصفح تحتاج Playwright. على هذا الجهاز تُربط بالحزمة العامة:

```bash
mkdir -p node_modules && ln -s /opt/node22/lib/node_modules/playwright node_modules/playwright
npm run test:e2e
```

## الاختصارات

| المفتاح | الوظيفة |
|---|---|
| ← / PageUp | الشريحة السابقة |
| → / PageDown / مسافة | الشريحة التالية |
| Home | أول شريحة |

| V | تشغيل/إيقاف فيديو الشريحة |

## أمان التصويت

- رمز المحاضر يُطلب عند تشغيل الخادم، ويُحفظ في الطرفية، ولا يظهر للطلبة. إن لم يُعيَّن `ADMIN_TOKEN` يُولَّد عشوائياً عند كل تشغيل.
- الطالب يرى سؤاله المفتوح وإجابته فقط، ولا يرى نتائج إلا بعد أن يُظهرها المحاضر.
- لا تُخزَّن أسماء ولا بيانات شخصية. الرمز المحلي للجهاز عشوائي ولا يربط الإجابة بشخص.
- يُقبل النص كنص فقط، ويُعرض بطريقة تمنع تنفيذ أي كود داخل الصفحة.
