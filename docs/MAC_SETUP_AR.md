# تشغيل ALFA Cognitive Stage على Mac — دون أوامر لكل محاضرة

## تجهيز البرنامج مرة واحدة

يلزم macOS، Google Chrome، Node.js 22، Python 3، LibreOffice، Poppler، FFmpeg ومكتبات Python. يمكن تثبيت المفقود بواسطة Homebrew:

```bash
brew install node python poppler ffmpeg
brew install --cask libreoffice
python3 -m pip install python-pptx lxml Pillow
```

## الاستخدام اليومي

1. افتح **Start ALFA.command** بالنقر المزدوج من مجلد المشروع. قد يحتاج macOS تأكيد تشغيل الملف أول مرة.
2. افتح `http://localhost:4173/#presenter` إذا لم تُفتح تلقائياً.
3. اقرأ رمز المحاضر من Terminal؛ لا تشاركه مع الطلبة.
4. اختر PPTX من الواجهة ثم «استيراد وفتح المحاضرة» مع رمز المحاضر.
5. لإعادة إلقاء المحاضرة، اخترها من القائمة؛ لا تحتاج برومبت أو سكربت جديد.
6. إذا أردت الاستماع، استخدم Chrome واسمح للميكروفون؛ يعمل الكشف عن الإحصائيات المحلية دون OpenAI.
7. للتصويت افتح لوحة التصويت داخل الاستوديو وانشئ جلسة. هواتف الطلبة تحتاج شبكة تسمح بالوصول إلى الماك.
8. لتحليل AI اختياري فقط، ضع `OPENAI_API_KEY` سرياً في `.env` المحلي، ولا ترفعه إلى GitHub.

## الحدود التي لا ينبغي تجاهلها

- **PowerPoint animations غير محفوظة** داخل صور الشرائح؛ تظهر تحذيرات لكل شريحة يُكتشف فيها توقيت/حركات.
- فيديوهات PPTX قد تحتاج فحص ترميز وصوت ومزامنة على Mac والبروجكتر الحقيقيين.
- Web Speech API قد يرسل الصوت إلى خدمة المتصفح. انعدام OpenAI API لا يعني التعرف الصوتي دون إنترنت.
- تحفظ العروض في `bundles/`، ومشاهد المحاضر المعتمدة في `data/scenes.json` محلياً ولا تُرفع إلى Git.
- الصور والفيديوهات المستوردة مقصورة على جهاز المحاضر، والتصويت فقط متاح للطلبة افتراضياً.
- إذا شغلت `ALFA_ALLOW_REMOTE_SLIDES=1` فسيسمح ذلك بالوصول إلى ملفات العرض على الشبكة؛ استخدمه فقط بعد تأمين الشبكة.
- وضع التصويت المحلي قد لا يعمل بشبكة جامعة تعزل الأجهزة، ولا يزال اختبار iPhone/Android الحقيقي ضرورياً.

## إعادة الشرح لشعبة ثانية

البصمة نفسها تعني إعادة استخدام الحزمة ووسائطها دون تحويل جديد. ويمكن مزامنة مشاهد المحاضر المخزنة محلياً برمز المحاضر، ولن يتطلب عرضها مكالمات API جديدة. المطابقة الحالية ليست ذاكرة دلالية عميقة.
