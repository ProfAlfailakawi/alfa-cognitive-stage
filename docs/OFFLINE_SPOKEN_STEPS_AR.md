# تحويل الخطوات المنطوقة إلى مشهد تعليمي محلي — 17 أكتوبر 2026

## التنفيذ الحقيقي
يستمع المخرج عبر المسار الصوتي الحالي (أو مربع اختبار النص) ويكتشف **ثلاث خطوات إلى ست خطوات متسلسلة وواضحة**، مثلاً: «أول شي نحدد الهدف، ثاني شي نصمم النشاط، ثالث شي نقيس الأثر»، أو «أولاً ... ثانياً ... ثالثاً ...». يحوّل الكلمات الأصلية إلى قالب steps SVG الموجود دون استدعاء API أو إضافة تفاصيل من عنده.

- يتطلب الترتيب من «أول» إلى «ثالث» على الأقل دون تخطي أو إعادة ترتيب، ويرفض الأقوال المقتضبة والمكررة أو الطويلة التي قد تُقطع وتشوّه المعنى.
- المخرج لا يفترض نتائج، دراسات، أسباباً، أو تواريخ. كل جملة في المشهد مشتقة من الجملة التي نطقها المحاضر؛ تطبيع الحروف والأرقام العربي فقط قد يغيّر شكل الكتابة لا المعلومات.
- يمكن للمحاضر تعداد المراحل في جملة واحدة أو ثلاثة مقاطع متقاربة (الواجهة حالياً تحتفظ بثلاث جمل قصيرة خلال 25 ثانية). إذا تأخر المقطع أو لم يتعرف المتصفح على الكلام، لا يُخترع مشهد.
- يعمل في الوضع المتوازن تلقائياً عند اكتمال الترتيب، دون مقاطعة فيديو يُعرض؛ والوضع المحافظ يستلزم موافقة صريحة، ووضع الظل لا يعرض شيئاً.
- مشاهد SVG المعتمدة يمكن حفظها واسترجاعها بالقواعد الموجودة؛ لا يُلزم المستخدم بأي برومبت أو واجهة جديدة.

## ما لم يُنفذ
هذه **مطابقة تسلسل لفظي محلي صارمة** وليست فهمًا دلاليًا عامًا أو تخطيطًا تربويًا مستقلًا؛ لا تكتشف ترتيبًا مبهمًا أو سلسلة مقاطع بعيدة زمنياً. لا توجد خدمة STT أوفلاين مؤكدة، ولا اختبارات ميكروفون Mac الفعلية. الحركات الأصلية لشرائح PowerPoint لا تزال غير محفوظة.

## الاختبارات
`npm run test:spoken-steps` يتحقق من الصيغ الكويتية والفصحى، وأرقام عربية، وسلامة ترتيب المراحل والرفض المحافظ للحالات المبهمة. `npm run test:e2e` يثبت اقتراح مشهد الخطوات وعرض الكلمات المنطوقة فقط والعودة الفورية في Chromium. كما تستمر اختبارات الفيديو والتصويت واستيراد PPTX.
