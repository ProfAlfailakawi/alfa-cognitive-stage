# حركات PowerPoint: خطوات البناء والعودة الدقيقة

## ما الذي يُحفظ فعلاً
عند استيراد PPTX يقرأ `tools/animations.py` قائمة الحركات الرئيسية (`p:timing` ← `mainSeq`) نقرةً نقرة، ويحسب ما يظهر بعد كل نقرة، ثم يرسم **صورة لكل حالة** بواسطة LibreOffice في `steps/NNN-KK.png`.

| العنصر | الحالة |
|---|---|
| ترتيب الظهور والاختفاء (Entrance/Exit) على الأشكال والصور | محفوظ — حالة كل نقرة مطابقة لنموذج الحركات |
| بناء النص فقرةً فقرة | محفوظ — الفقرات غير الظاهرة تُخفى دون تحريك بقية النص |
| مخططات PowerPoint: بناء بحسب السلسلة أو الفئة أو النقطة | محفوظ — تُخفى النقاط غير الظاهرة مع بقاء المحاور والمقياس ثابتين |
| «مع السابق» و«بعد السابق» و«تلقائي عند بدء الشريحة» | تُجمع في نقرة واحدة؛ الشرائح التي تبدأ تلقائياً تتقدم وحدها (وفق التأخير المسجل) |
| شكل الحركة ومدتها (طيران، مسح، تكبير…) | **تقريبي**: تلاشٍ هادئ واحد بين الحالتين؛ لا نُعيد اختراع حركات بديلة |
| حركات التأكيد ومسارات الحركة | غير مدعومة — تُسجل تحذيراً ويبقى ترتيب الظهور |
| SmartArt المتحرك، الحركات التفاعلية بمحفزات، مخططات OLE | غير مدعومة — تعرض الشريحة بحالتها النهائية مع تحذير صريح |
| المخططات المبعثرة/الفقاعية/الأسهم | غير مدعومة في خطوات المخطط — تعرض كاملة مع تحذير |
| بناء النص بالكلمة أو الحرف | غير مدعوم — تحذير |

الاعتماد على صور لكل حالة ليس «محاكاة» لحركة؛ هو تمثيل أمين لما تراه الشاشة بعد كل نقرة. ما لا يمكن تمثيله يُكتب في لوحة «جاهزية العرض».

## المشغل
- زر «التالية» أو السهم يقدّم نقرة واحدة، وعند آخر نقرة ينتقل إلى الشريحة التالية. «السابقة» تتراجع نقرة، ومن بداية الشريحة تهبط على الحالة النهائية للشريحة السابقة.
- عند النقر السريع يجب إلغاء أي صورة قديمة اكتمل فك ترميزها متأخراً؛ هذا يحمي ترتيب الحالات المصورة فقط ولا يحفظ حركة PowerPoint الأصلية.
- نافذة الطلبة تتبع الحالة نفسها. إضافة مشهد ذكي لا تعيد تشغيل الشريحة ولا تغير صورة الحالة.
- انتقال الشرائح تلاشٍ واحد هادئ كما كان.

## العودة الدقيقة بعد الاستطراد
قبل ظهور أي مشهد أو QR يلتقط الاستوديو: الشريحة، ونقرة الحركة، وموضع كل فيديو وهل يعمل، والمشهد المعروض. ثم:
- `E` / `Esc` / «نرجع للعرض»: عودة كاملة إلى الحالة الأصلية قبل أول استطراد.
- «نرجع للي قبل» / «نرجع للموضوع السابق» أو زر «إخفاء»: خطوة واحدة للخلف في الاستطراد المتداخل.
- التنقل العادي يعني أن المحاضر استأنف المحاضرة، فيُمسح المرجع القديم.

## الحدود الصادقة
- الاختبارات استخدمت ملفات PPTX اصطناعية بُنيت بنية `p:timing` على غرار ما يكتبه PowerPoint، وليس ملفاتك الفعلية. قارن أول محاضرة حقيقية مع PowerPoint (إجراء القبول 1 في SPEC_STATUS_AR).
- الرسم بـLibreOffice قد يختلف قليلاً عن PowerPoint في الخطوط والمخططات المعقدة.
- لا يوجد تكامل مع PowerPoint الأصلي على macOS؛ هذه تقنية مختلفة (AppleScript/تشغيل شاشة PowerPoint) لم تُنفذ ولم تُختبر.
- المحاضرات المستوردة قبل هذه النسخة تُحدّث تلقائياً عند إعادة استيراد الملف نفسه.
