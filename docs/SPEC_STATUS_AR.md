# ALFA Cognitive Stage — التدقيق الشامل للمواصفات والتنفيذ

**تاريخ المراجعة: 17 أكتوبر 2026.** هذا المستند يميز بين تنفيذ برمجي مثبت، وتنفيذ يحتاج اختباراً فعلياً، وميزة لم تُنفذ. الهدف هو عدم الخلط بين نجاح اختبارات GitHub وبين الجاهزية داخل قاعة جامعية على جهاز Mac.

## مبادئ التصميم غير القابلة للتنازل

- **لا برومبت لكل محاضرة:** يفتح المحاضر أي PPTX ويُحضر النظام نص الشرائح وملاحظاتها تلقائياً. ما زالت جودة النتائج مرتبطة بوضوح المحتوى، والتفاعل الصوتي ليس فهمًا شاملاً بعد.
- **المحتوى من المحاضر:** لا يجري النظام بحثاً تلقائياً عن الدراسات، ولا يخترع مصادراً أو أرقاماً. الرسومات تصف ما سمعه أو ما وُجد في الشريحة.
- **حركة بسيطة:** الانتقال بين الشرائح تلاشٍ واحد هادئ؛ النقرات الأصلية تُعرض كحالات مرتبة (انظر الجدول).
- **الفيديو أولوية:** استخراج الفيديو ومزامنته برمجياً موجودان، مع اختبارات Chromium؛ الاختبار مع البروجكتر والصوت في Mac ما زال مطلوباً.
- **صفر API متى أمكن:** كشف الإحصائية محلي، وSVG محلي، ومكتبة المشاهد المعتمدة محلية. التعرف الصوتي في Chrome قد يستعين بخدمات المتصفح؛ عدم استعمال OpenAI ليس ضماناً لأوفلاين حقيقي.
- **لا تبديل يدوي بين PowerPoint وHTML:** يتم تحميل PPTX إلى واجهة واحدة، لكن العرض ينتقل لصور الشرائح، وليس محرك PowerPoint الأصلي.
- **المشهد يُلغى فوراً:** العودة تحافظ على موضع المحاضرة وتوقف الفيديو، وتخفي الإنفوجرافيك وQR. التفاصيل الدقيقة لخطوة حركة PowerPoint غير مدعومة.
- **كلفة منخفضة:** الرسومات SVG ولا تُولد صور ضخمة. GPT API اختياري، وله حد عدد طلبات في عملية الخادم وسقف يومي محفوظ محلياً وعدّاد توكنات فعلية أو مجهولة. التسعير بالدولار تقديري من جدول أسعار مؤرخ، ولا يوجد كشف فواتير من المزود.

## الاختبارات المنفذة آلياً

- وحدة Node: الرسم، محرك أحداث عربي، حماية AI، الذاكرة، تفضيلات التجاهل المحلية، الجولات، الاستيراد، الأمان وجاهزية العرض.
- Python: نص الشرائح، التحويل والكشف عن الحركات، وفهرسة الحزم.
- Chromium: عرض محاضر/طلبة، التنقل والفيديو والعودة وQR، واستعادة نافذة طلبة متأخرة، مع اختبار pause/seek وتصحيح فرق الفيديو؛ ليست أجهزة Mac أو هواتف حقيقية.
- Chromium: 5 أجهزة متصفح افتراضية للتصويت؛ **ليست خمسة هواتف حقيقية**.
- PowerPoint حقيقي مصطنع في CI: تحويل عبر LibreOffice إلى صور والتحقق من النص والملاحظات والمطابقة عند الإعادة.

## اختبار قبول محلي مطلوب قبل المحاضرة الحقيقية

1. تجربة 3 ملفات PPTX متنوعة تخص المحاضر، بينها ملف فيديو وشرائح إحصائيات متحركة.
2. مقارنة مرئية مع PowerPoint على نفس Mac للتحقق من اختلاف الخطوط/الأشكال.
3. تجربة شاشة البروجكتر والصوت والتحكم بجهاز العرض (نافذة المحاضر/نافذة الطلبة).
4. تجربة ميكروفون Chrome باللهجة الكويتية ومراقبة التأخير وموافقة المتصفح.
5. تجربة 5 هواتف فعلية على شبكة الجامعة والرسائل بعد حظر اتصال مباشر.
6. تجربة قطع الإنترنت وفتح المحاضرة والتصويت المحلي واستكمال الشرح.
