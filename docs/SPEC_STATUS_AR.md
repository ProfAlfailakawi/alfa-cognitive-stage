## فجوات P0 — لا يجوز وصف النظام بالجاهز للقاعة دونها

1. **حركات الإحصائيات والأنيميشن في PowerPoint**: تحويل الشرائح إلى PNG يعرض حالتها النهائية، وليس الحركة. يلزم محرك متوافق أو إخراج فيديو للحركة.
2. **فيديوهات Mac الحقيقية**: يلزم اختبار الترميزات، الصوت، الشاشة الثانية، التحكم، وحالة وجود أكثر من فيديو في الشريحة؛ المشغل الحالي يعرض أول فيديو فقط.
3. **الاستماع باللهجة الكويتية**: Web Speech قد يستخدم خدمات خارجية؛ لا يوجد ضمان لأوفلاين أو زمن استجابة ثابت.
4. **مخرج دلالي شامل**: القواعد المحلية تعرف بعض العبارات فقط؛ GPT API اختياري ويقترح رسوماً من ثلاثة أنواع، وليس مخرجاً روائياً متكاملاً.
5. **الدراسات والمعلومات**: لا بحث تلقائياً وفق طلب المحاضر؛ نص الإحصائية يؤخذ من المحاضر فقط، وقد يحتاج منه تصحيحاً.
6. **التصويت في الجامعة**: يحتاج اختبار iPhone/Android ووجود إمكانية اتصال مباشر بين الأجهزة؛ وإلا يلزم استضافة آمنة.
7. **حماية واجهة المحاضر**: واجهة العرض الحالية نفسها عامة على الشبكة؛ رمز الإدارة يحمي API للتصويت/AI لكنه ليس مصادقة شاملة للشاشة.
8. **بروفة القاعة**: يلزم اختبار end-to-end على الماك ومعالجة انقطاع الشبكة أو تعطل الذكاء.
9. **العودة لحالة الحركة أو الفيديو الدقيقة**: المرجع الحالي رقم الشريحة؛ حالة الأنيميشن المتقدمة ليست مدعومة.

## قيود أمن وخصوصية

- Web Speech API في Chrome قد يرسل الصوت إلى خدمة للمتصفح. عدم استخدام OpenAI API لا يعني أن معالجة الصوت محلية.
- منفذ OpenAI على الخادم فقط ومحمية الطلبات برمز الإدارة، ولا يجوز نسخ المفتاح إلى المتصفح.
- DIRECTOR_MAX_CALLS يحسب الطلبات، لا بالدولار أو التوكنات.
- الإحصائيات تُنقل من كلام المحاضر ولا يتم التحقق منها مقابل دراسة، بناءً على طلبه.
- اختبار Node/Chromium ليس دليلاً على نجاح iPhone وMac وشاشات الجامعة.

## قبول متدرج

1. تفحص ملف PPTX يحوي الفيديو وحركة إحصائية.
2. تختبر الشريحة رقم 12 ثم مفتاح E فترجع للشريحة 12.
3. تختبر خمس هواتف حقيقية، وQR المحلي أو رابط استضافة، وجولة مكررة.
4. تختبر المايك باللهجة الكويتية، وتصحيح نسبة، واستطراد ثم عودة.
5. تختبر انقطاع API واستمرار العرض.
6. تختبر إنشاء مشهد سحابي بمفتاح محلي وموافقة قبل عرضه.
7. تثبت أن وضع صفر API لا يرسل طلبات API مع محرك صوت محلي إذا طُلبت خصوصية أوفلاين كاملة.

لا تدّعِ إكمال أو دمج كل المواصفات قبل اجتياز اختبارات القاعة الفعلية.
