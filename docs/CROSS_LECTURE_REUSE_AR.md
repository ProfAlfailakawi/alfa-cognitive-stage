# إعادة استخدام المشاهد عبر المحاضرات — 17 أكتوبر 2026

## التنفيذ
عند حفظ مشهد سبق عرضه، يُضاف إلى فهرس localStorage محلي عابر للمحاضرات، مع إبقاء ذاكرة المحاضرة الأصلية. تُفضّل المطابقة من المحاضرة الحالية. إذا لم توجد، يُقترح مشهد محفوظ من محاضرة أخرى فقط عند اشتراك ثلاث كلمات مهمة على الأقل وتشابه جاكارد لا يقل عن 0.85 وتطابق جميع الأرقام والنسب. لا يُعرض المشهد المستعاد تلقائياً؛ يستخدم زر موافقة المحاضر المعتاد. لا تُستدعى أي واجهة API مدفوعة. الفهرس محدود بآخر 150 مشهداً.

## الحدود والخصوصية
هذه **مطابقة لفظية محافظة وليست ذاكرة دلالية**؛ قد لا تتعرف على إعادة الصياغة. الفهرس محصور في متصفح المحاضر وعلى نفس الأصل؛ لا يتزامن تلقائياً مع الأجهزة الأخرى. يحفظ كلمات مفتاحية وأرقاماً ومحتوى الرسم، لا نسخة ثانية من الجملة الصوتية كاملة. يجب عدم استخدام متصفح مشترك مع الطلبة، ومراجعة كل اقتراح قبل العرض. مسح بيانات الموقع يزيل ذاكرة المتصفح فقط، لا ملف ذاكرة الخادم. المشاهد التي تزامنها من الخادم إلى المتصفح تُفهرس أيضاً.

## التحقق
`npm run test:memory` يفحص إعادة الاستخدام بين المحاضرات، وتغير الأرقام، وعزل متصفح آخر، وأولوية المحاضرة الحالية، وحد 150 مشهداً. لم يُختبر على Mac أو هواتف فعلية. لم تُنفذ embeddings أو مزامنة متعددة الأجهزة.
