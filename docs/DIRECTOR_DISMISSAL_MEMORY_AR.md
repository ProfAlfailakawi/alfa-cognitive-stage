# ذاكرة تجاهل اقتراحات المخرج — 17 أكتوبر 2026

## الهدف
عند ظهور اقتراح بصري من المخرج الخفي وضغط المحاضر **«تجاهل»**، يتذكر هذا المتصفح القرار ضمن **المحاضرة والشريحة والعبارة نفسها فقط**. إذا عاد النص نفسه بعد تطبيع الأرقام العربية وعلامات الترقيم، لا يعرض الاقتراح مرة أخرى ولا يبدأ تحليلاً سحابياً مدفوعاً جديداً لهذه العبارة، حتى بعد تحديث الصفحة.

## الاستخدام
- زر **«تجاهل»** يحفظ القرار تلقائياً محلياً عندما تتوفر ذاكرة المتصفح. بدون localStorage يظل التجاهل الحالي عاملاً، لكن لا تحفظ الأفضلية.
- زر **«مسح الاقتراحات المتجاهلة لهذه المحاضرة»** يرجع اقتراحاتها للعمل مجدداً. لا يحذف المشاهد المعتمدة أو مكتبة الخادم ولا يرسل طلب API.
- الحالات المفحوصة: لفظ مطابق مع اختلاف الأرقام العربية/الغربية أو الترقيم، رفض مكرر، تغيير الرقم، الانتقال لشريحة/محاضرة أخرى، متصفح آخر، ورفض التخزين.

## الحدود والخصوصية
- يحتفظ المتصفح ببصمة رقمية بسيطة للعبارة ورقم الشريحة وتوقيت القرار؛ **لا يحفظ نسخة إضافية من النص المنطوق** ولا يُرسل تفضيلات الرفض إلى الخادم. البصمة غير تشفيرية ولا تضمن إخفاء مضمون عبارات يسهل تخمينها؛ لا تشارك ملف المتصفح مع الطلبة.
- أضيق نطاق متعمّد: نفس ملف المحاضرة ونفس الشريحة والنص المطبع نفسه. إعادة الصياغة أو استطراد مختلف لن يُكبتا. هذه ذاكرة قرار محافظة **وليست تعلماً دلالياً لشخصية المحاضر**.
- مدة الرفض 14 يوماً من آخر تجاهل، بحد أقصى 80 قراراً لكل محاضرة، وتُستبعد السجلات المنتهية أو الفاسدة. يمسح المستخدم البيانات عبر الزر أو بيانات الموقع.
- العودة إلى العرض والفيديو تبقيان مستقلتين. لا تُكبت إشارات «نرجع للعرض». لن يمنع الكود كل استدعاء AI محتمل بعبارات متباينة، ولا يعني ذلك وجود حد تكلفة بالدولار.
- لا يستخدم OpenAI ولا خدمات خارجية في هذه الذاكرة. التعرف الصوتي للمتصفح قد يظل بحاجة إلى خدمة خارجية.

## الاختبارات
`npm run test:preferences` يتحقق من شروط المطابقة والخصوصية والحد والمهلة والتعامل مع أخطاء التخزين؛ و`npm run test:e2e` يتأكد من ربط زر تجاهل الاقتراح وزر مسح الذاكرة في واجهة Chromium. لا يوجد اختبار على Mac أو هاتف فعلي.
