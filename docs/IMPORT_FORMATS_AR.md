# الاستيراد والتوافق: PPTX وPDF وKeynote والفيديو

| الصيغة | الحالة | ما يُحفظ | ما لا يُحفظ |
|---|---|---|---|
| **PPTX** | مدعوم بالكامل (المسار الأساسي) | صور الشرائح، النص والملاحظات، نقرات الحركة (انظر `PPTX_BUILD_STEPS_AR.md`)، الفيديو المضمن | حركات التأكيد/المسارات وSmartArt |
| **PDF** | مدعوم فعلياً ومختبر | صفحة = شريحة، نص كل صفحة للمخرج | لا حركة ولا فيديو (PDF لا يحملها) |
| **Keynote (.key)** | محاولة على قدر الإمكان، **غير مختبر بملف Keynote حقيقي** | عبر LibreOffice → PDF | الحركات والفيديو المضمن. الأفضل: في Keynote «ملف ← تصدير إلى ← PowerPoint» ثم ارفع الناتج |

- يُتحقق من **محتوى** الملف لا اسمه فقط (PDF يبدأ بـ `%PDF-`، وPPTX/Keynote أرشيف مضغوط)، وبحد 80MB و400 صفحة PDF. لا تُنفذ أي سكربتات في PDF (يُرسم بواسطة poppler فقط). PDF المشفر يُرفض برسالة واضحة.
- PDF مصوّر بلا نص (مسح ضوئي): يعمل عرضاً لكن المخرج لا يقرأ محتواه، ويظهر تحذير.

## الفيديو
- لكل فيديو يُفحص: الترميز (فيديو/صوت)، صيغة البكسل، الأبعاد، وجود صوت.
- **H.264 8-bit 4:2:0 بأبعاد زوجية وAAC** ← نسخ مباشر بلا إعادة ترميز. غير ذلك (H.264 4:4:4 أو 10-bit، MPEG-4، MOV بترميزات قديمة، أبعاد فردية…) ← يُحوَّل إلى H.264/AAC ويظهر في التحذيرات «تم تحويل الفيديو».
- فيديو بلا مسار صوت ← تحذير «لا يوجد صوت».
- فيديو لا يُقرأ أو يتعذر تحويله ← تحذير للشريحة نفسها، ولا يفشل استيراد المحاضرة كلها.
- فيديو خارجي/إنترنت (رابط) ← تحذير صريح؛ لا يُنزّل قسراً.
- فحص فك الترميز داخل المتصفح (زر الجاهزية) يبقى الفحص النهائي على جهاز المحاضر.
- نسخة WebM احتياطية: `ALFA_WEBM_BACKUP=1` (مكلفة، اختيارية).

## الحدود
اختُبرت ترميزات اصطناعية (H.264 بأنواعها، MPEG-4/MP3، أبعاد فردية، بلا صوت، ملف تالف). لم تُختبر فيديوهات HEVC أو ProRes أو ملفات من كاميرات حقيقية، ولا صوت البروجكتر.
