# ذاكرة المشاهد المعتمدة العابرة للمحاضرات — استعادة من الخادم المحلي

**تاريخ التحديث: 17 أكتوبر 2026.**

## التنفيذ
- كل مشهد يوافق عليه المحاضر محفوظ مسبقاً في ملف `data/scenes.json` وفق معرّف المحاضرة. أصبحت واجهة `GET /api/memory/library` تجمع آخر **150 مشهداً معتمداً** من مختلف المحاضرات، عبر رمز المحاضر فقط، مع ترتيب الأحدث أولاً.
- عند «مزامنة المشاهد المعتمدة محلياً» تستعيد واجهة المحاضر مشاهد المحاضرة الحالية أولاً، ثم الفهرس العام المحمي، وتُعيد بناء فهرس المشاهد المحلي المحدود عبر محاضرات متعددة. لا يتكرر إرسال محتوى إلى خدمة خارجية ولا يلزم API مدفوع.
- تستفيد حتى نافذة متصفح منفصلة أو ملف شخصي متصفح جديد **إذا كان متصلاً بخادم المحاضر المحلي نفسه ويحمل رمز المحاضر**. لا حاجة إلى إدخال برومبت جديد لكل ملف.
- أي مشهد مأخوذ من محاضرة أخرى يظل اقتراحاً يحتاج موافقة المحاضر قبل العرض؛ تطابق النسب والأرقام والكلمات المهمة كما في `web/scene-memory.js` ولم يُخفّض معيار القبول.
- لا تعرض ذاكرة المشاهد للطلبة، ولا يمكنهم قراءة سجل العبارات المعتمدة: نقطة النهاية تستلزم رمز الإدارة وتُرجع `Cache-Control: no-store`. المسار العام للقراءة فقط.

## حدود وأمان
- المشاهد المحفوظة تشمل النص الأصلي للعبارة التي وافق عليها المحاضر؛ الخادم المحلي **ليس مستودعاً مجهول الهوية**. لا تُدخل معلومات خاصة عن طالب. حافظ على سرية رمز المحاضر واحمِ القرص المحلي.
- الاسترجاع لفظي محافظ، وليس embeddings أو فهماً دلالياً عاماً. لا تتزامن المشاهد عبر خوادم Mac مختلفة أو عبر سحابة مستضافة؛ يلزم استخدام الخادم المحلي ذاته.
- يبقى حد ذاكرة المتصفح 150 مشهداً، وذاكرة كل محاضرة 50 مشهداً، وحد الخادم لكل محاضرة 120 مشهداً. إذا تجاوزت المكتبة حدود الفهرس فلن تظهر المشاهد الأقدم في اقتراحات المتصفح حتى عند وجودها على القرص.
- أي ملف مشهد غير صالح لا يوقف مزامنة المشاهد السليمة. لا تُولد أرقام أو مصادر جديدة.
- هذه الميزة لا تعالج حركات PowerPoint الأصلية ولا تضمن صوتاً/ميكروفوناً محلياً بالكامل.

## اختبارات القبول
- `npm run test:scene-store`: الاستمرارية بعد إعادة تشغيل الخادم، التنقل بين عدة محاضرات، ترتيب المشاهد الأحدث، حد 150، وعزل النسخ الداخلية.
- `npm run test:e2e`: حفظ المشهد المعتمد، منع قراءة الطالب للفهرس، مزامنة محاضر جديد في ملف متصفح معزول، استرجاع مشهد محاضرة سابقة دون API، ومنع إعادة الاستخدام إذا تغيرت النسبة.
- اختبارات استيراد PPTX والفيديو والمحاضر/الطلبة والتصويت تبقى إلزامية قبل الدمج.
